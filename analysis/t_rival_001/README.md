# T-RIVAL-001: scalar n=3 versus effective-fluid CMB rival

Canonical decision: `NO_COHERENT_SCALAR_SPECIFIC_CMB_PREFERENCE`.

The canonical PEER scalar n=3 fixed template was compared with an acoustically near-matched w=1/2 effective-fluid rival using Planck 2018 TTTEEE plik-lite, ACT DR6 TT/TE/EE, and SPT-3G D1 TT/TE/EE. Eleven exact scalar CAMB nuisance tangent bases were replayed locally.

Results:
- Planck Delta chi-square scalar minus fluid: -5.257 to -3.492, scalar favoured in 11/11 bases.
- ACT DR6: +2.500 to +3.779, fluid favoured in 11/11 bases.
- SPT-3G: -0.438 to +0.223, nearly neutral.
- Independent-profile diagnostic sum: -2.988 to +0.509, crossing zero.

Conditional channel attribution at the valid joint TT+TE+EE best fits shows that Planck's pull is dominated by EE, while ACT favours the fluid in TT, TE, and EE. Independent per-channel fits were attempted but 59/99 were rank-deficient and are retired as blocked outputs.

Claim boundary: the rival matches rdrag and thetastar approximately, not the complete background history, and uses the same scalar nuisance tangent basis. The result is sufficient to reject a coherent experiment-independent scalar-specific signature at this diagnostic level. It is not a final native AdS-EDE/NEDE comparison.
